# Metric definitions (Legacy alias for Features)

> [!NOTE]
> In BIM, `metrics` is now the backward-compatible alias for `features`.
> See the primary documentation at [Feature definitions and informative templates](FEATURES.md).

For backward compatibility, BIM schemas and tools continue to support `metrics`, `metricBindings`, `requiredMetrics`, and related metric fields as aliases for their canonical `features` counterparts.
