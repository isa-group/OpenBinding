States and recoverable errors

Every action can fail even when the screen allowed it. These are the messages the prototype reuses, each with what happened and how to recover. Two error shapes come from the API (problem+json and detail objects); the screens show them the same way.

How an error becomes a message

The platform answers errors in two formats. Both are turned into the same kind of message, so people never see the raw answer. Left: what the answer carries. Right: where it shows.
