Decisions and deviations
  • No prices or checkout anywhere: paid plans read “Contact us / Institutional agreement”. Pricing is labelled development copy 0.1.0.
  • capacityUnits is flagged “To confirm” because its meaning isn't settled in the handoff.
  • The pricing token is internal: Usage shows its state (valid, stale, missing) as plain-language banners, never the token itself.
  • Admin-only key permissions appear locked with an explanation, so nothing implies a MANAGEMENT or ALL key from the browser.
  • No Expert view: everything in the pricing document is shown visually (plan descriptions, exact values under rounded figures, which features each limit applies to, and what must have room before starting a solve, federated solve or study run). The deprecated GET /v1/pricing isn't used.
  • Domain-1 links that pointed to the index now open these screens (header user menu, palette, footer, Home, Register, CAS return, State gallery, Engines).
