Decisions and deviations
  • UX reference switched to SPHERE 8472610 (your answer), the same source as the design system. Header, footer, stripe band, auth split layout, command palette, notifications and card anatomy come from it.
  • Persona choice persists across boards in this browser; state and scenario are per screen.
  • Links to screens of later domains land on the Screen index, which says which domain builds them.
  • invitation accept: the organization and role appear only after accepting, because the contract has no preview endpoint.
  • Plan ceilings on engine options are computed from pricing 0.1.0; the max_evaluations ceiling isn't mapped in the docs, so it's labelled as such.
  • “Canonical” removed from visible copy at your request.
  • No Expert path: raw JSON/YAML views were removed from Verify, Workbench, Engine detail, Schemas and the State gallery; their content is shown as chips, field trees, diagrams and plain-language locations.
