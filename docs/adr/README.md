# Architecture decision records

The decisions F0b (re-anchoring: the organization as the only container, simple storage) recorded. Each record names
the decision of the F0b implementation plan it comes from. The earlier records, 0001 to 0021, were removed with the
factory process artifacts (commit `e47da50d5`) and remain in git history; these continue their numbering.

In the records, gateway sources (`routes/`, `modules/`, `db/`, …) are relative to `openbinding-gateway/src/openbinding_gateway/`,
and `tests/` and `tools/` without a prefix to `openbinding-gateway/`.
