Software and reproducibility artifact accompanying "QACOBench: A Reusable Benchmark Suite for QoS-Aware Service Composition" (BenchSOC@ICSOC 2026). This release archives the OpenBinding repository, including the gateway, solver engines, QACOForge generator, BIM schemas, original benchmark source inputs, transformation scripts, Docker configuration, QFBS design settings, documentation and experiment notebooks. It also includes the recorded QACOBench campaign results (46,350 submissions to three solvers with a 5,000 ms budget), evaluation tables, figures, secondary analyses, executed notebooks and run metadata. The exact engine (minizinc-csp) supports additive, min/max and multiplicative aggregations and placement capacities, and is pinned to MiniZinc 2.8.7 / Gecode 6.3.0; the campaign tooling records engine revisions, termination reasons and the reconciliation acceptance tests. The 15,450-instance BIM corpus is distributed in the separate QACOBench BIM dataset deposit. Extract the dataset archive into the software directory to use the experiment scripts (tools/package_zenodo.sh rebuilds both archives). CC BY 4.0 applies to the original contributions.
