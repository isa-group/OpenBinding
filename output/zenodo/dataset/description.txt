BIM dataset accompanying "QACOBench: A Reusable Benchmark Suite for QoS-Aware Service Composition" (BenchSOC@ICSOC 2026). QACOBench contains 15,450 portable BIM v1 instances across seven suites: 48 OpenBinding literature scenarios, 46 quantum-resource instances, 10,000 HSC workflows, 60 RPRSR15 instances, 6 IoTS instances, 90 BWS-SCP instances and 5,200 QFBS instances. The six recovered suites contain 10,250 instances. QFBS contains 2,600 feasibility-guaranteed and 2,600 non-guaranteed instances, using 26 configurations and 100 seeds per configuration in each group. HSC, RPRSR15 and BWS-SCP use source-faithful encodings (the soft squared-violation penalties of the HSC paper; source branch probabilities, loops, probability-scaled availability/successability and attained normalisation ranges for RPRSR15; the source MILP objective with log-reliability and the server capacities as a placement overlay for BWS-SCP), and every recovered package records its provenance and fidelity facts in benchmark metadata. The archive includes the instance resources, per-instance metadata and the QFBS generation manifest.
